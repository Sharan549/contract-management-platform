===============================================
GITHUB UPLOAD GUIDE - QUICK STEPS
===============================================

STEP 1: INSTALL GIT (if not installed)
---------------------------------------
1. Download: https://git-scm.com/download/win
2. Install with default settings
3. Restart VS Code/terminal after installation

STEP 2: OPEN TERMINAL IN VS CODE
----------------------------------
1. Press Ctrl + ` (backtick) to open terminal in VS Code
2. Make sure you're in the project folder

STEP 3: INITIALIZE GIT
-----------------------
git init

STEP 4: ADD ALL FILES
----------------------
git add .

STEP 5: MAKE FIRST COMMIT
--------------------------
git commit -m "Initial commit: EURUSYS Contract Management Platform"

STEP 6: CREATE REPOSITORY ON GITHUB
------------------------------------
1. Go to https://github.com and login
2. Click "+" icon → "New repository"
3. Name: eurusys-contract-management-platform
4. Description: Professional Contract Management Platform
5. Choose PUBLIC (required for submission)
6. DO NOT check any boxes (no README/gitignore)
7. Click "Create repository"

STEP 7: CONNECT LOCAL REPO TO GITHUB
--------------------------------------
Copy the commands GitHub shows you, or use:

git remote add origin https://github.com/YOUR_USERNAME/eurusys-contract-management-platform.git

(Replace YOUR_USERNAME with your actual GitHub username)

STEP 8: PUSH TO GITHUB
-----------------------
git branch -M main
git push -u origin main

If asked for credentials:
- Username: Your GitHub username
- Password: Use a Personal Access Token (NOT your password)
  → Create token at: GitHub Settings → Developer settings → Personal access tokens

STEP 9: VERIFY
--------------
1. Go to your GitHub repository page
2. Check that all files are there
3. Verify README displays correctly

STEP 10: SUBMIT
---------------
Submit your repository link at:
https://forms.gle/UBgZW7bKiWbFd6RU9

===============================================
TROUBLESHOOTING
===============================================

If "git is not recognized":
- Git is not installed → Install from step 1
- Close and reopen VS Code after installing Git

If "remote origin already exists":
git remote remove origin
git remote add origin https://github.com/YOUR_USERNAME/repo-name.git

If authentication fails:
- Use Personal Access Token, not password
- Generate token: GitHub Settings → Developer settings → Personal access tokens
